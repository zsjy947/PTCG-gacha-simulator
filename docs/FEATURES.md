## 一、产品定位

简体中文宝可梦卡牌（PTCG）**拆卡模拟器**：按官方发售规格开包，概率模型全程公示透明，
配套收藏册、卡值回本与完整卡表。三端（Windows exe / 安卓 APK / 微信小程序）共用同一
拆卡引擎与卡表数据，零后端、本地存储。

## 二、已上线功能（截至 v1.3.1）

### 拆卡核心
- 按商品线分类的弹包选择（补充包 / 收集啦151 / 宝石包 / 对战派对等 10 组），弹名/弹代码搜索
- 有公开随机包规格的弹按官方规格动态生成拆卡入口：5张瘦包、20张肥包、25张装、
  太晶盛聚 10张装（7+3/6+4 封入变体）、宝石包 4张全闪、奖赏包 1张装、30周年 6张全闪（必出特款皮卡丘）
- 单包 / 十连 / 整盒（按真实盒规：瘦包 30 包/盒、肥包与 25张装 6 包/盒、宝石包 18 包/盒等）
- 撕包动画、逐张 3D 翻卡、高稀有度光效、自动翻卡开关、包号页码导航、再来一次

### 概率与透明度
- 概率公示：每弹每规格每槽位（平卡位/闪卡位）的概率与卡池大小，含封入变体分列；每规格附「整盒理论」折叠块（一盒平均该出什么：各稀有度期望张数/盒与出现率，无盒规规格不显示）
- 划档概率模型完全可配置可审计（`config.py` 权重 + 按弹覆盖表），稀有度 100% 理论可达有测试守卫
- 目标卡期望成本：「单卡 / 集齐」两页签——单卡为几何分布模型；集齐支持稀有度全部、RR+ 及以上（闭式公式 n·H_n/λ）与收藏册缺卡（固定种子蒙特卡洛，分批计算不阻塞、可取消，给出期望/中位/P90 包数与完成率）
- 实测对照：拆卡统计各稀有度实测占比 vs 划档模型期望占比的偏差对照（正绿负红，样本 ≥30 包自动展开，不足折叠注明仅供参考）；小程序出货分布叠加理论基准条与同款对照表

### 收藏与统计
- 收藏册：每弹完成度进度条、「只看缺卡」模式、按价格排序、卡牌总价
- 缺卡清单导出：缺卡图（对齐战报布局，每页 60 张自动分页，逐格标注编号/卡名/稀有度）与文本清单（复制到剪贴板），无缺卡时按钮置灰
- 收藏册 JSON 导入/导出（三端互通，合并式写入）
- 拆卡记录（上限 30 条）与每弹统计（包数/张数/RR+ 计数/最高稀有度/出货分布图）
- 消费统计：按官方建议零售价记账、总花费/平均每包/按弹明细、一键清零与记账开关

### 卡值与回本
- 开包结果显示卡值与回本率（≥100% 绿 / 不足红），单包小结与十连/整盒汇总条均显示
- 卡价静态快照（集换社行情，人民币口径）每周一由 GitHub Actions 自动同步入仓
- 客户端启动静默检查并热应用新快照，无需升级程序；设置页显示快照统计与手动检查

### 浏览与工具
- 完整卡表浏览：增量渲染、稀有度筛选、卡名搜索、无限滚动
- 卡牌详情：简中效果文本、HP/属性/招式/画师（代理缓存远端详情接口）
- 拆卡战报图：canvas 生成当前卡包战报，PC 下载 / APK 存相册

### 数据与更新
- 卡表数据同步：`fetch_data.py` 从 mik.moe 拉取 134 弹简中卡表，生成数据清单 manifest
- 卡表热更新：设置页按 manifest 增量比对，只下载有差异的弹，支持一键恢复内置
- 应用更新检查：发现新版提示并给出当前平台安装包直链
- 图片按需加载 + 磁盘缓存（webp 缩略图、LRU 上限、占用查询与一键清空）
- 卡图按弹预缓存（exe/APK）：一键预取当前弹全部卡图（默认缩略图，可选含原图），断网可完整浏览该弹；进度弹窗可随时中止，缓存占用超上限 80% 时先确认；小程序不放该入口

### 平台与体验
- Windows exe：PyInstaller 免安装单文件，自动起本地服务并开浏览器
- 安卓 APK：纯资产模式（无后端），WebView 直连图源，原生图缓存 500MB 最旧淘汰
- 微信小程序：零后端，卡表裁剪内嵌（主包 2MB 内），图源直连；存储按弹分键规避 1MB 上限
- 深浅色主题（记忆保存）、应用内确认弹窗与 toast、PC 应用窗口式布局
- 持久化：localStorage（`ptcg_*` 键）+ 磁盘镜像 rev 协议，重启/换端不丢数据

## 四、明确不做

- **概率篡改类**（保底、跳过、概率修正）：产品立身之本是划档模型真实性；
- **卡价历史曲线 / 投资分析**：静态快照 + 回本率已覆盖需求，避免滑向财务工具；
- **排行榜 / 云同步 / 账号体系**：三端零后端架构是成本与合规优势，不为社交引入服务端；
- **签到 / 体力 / 成就墙 / 皮肤**等游戏化包装：与"透明概率公示工具"气质冲突。

另见 ARCHITECTURE.md「历史重构记录」中留档保留项——那些是已知且有意保留的工程取舍，不属于待办。
